# RELAY — 70 / 30 종이 모델

종이에는 `70`, `30` 두 숫자만 있다. 얇은 종이, 약간 들린 아래쪽 모서리, 위쪽 마스킹 테이프 하나로 구성했다. 종이 본체는 약 30 × 42cm다.

Unity는 직접 조작하거나 수정하지 않았다. 아래 적용은 사용자가 진행한다. 이 모델은 외형이며 POWER 판정과 클릭 확대 기능은 앞서 제공한 `POWER_HINT_v01` 코드를 사용한다.

## 1. 파일 가져오기

Play를 정지하고 씬을 저장한다. Unity Project 창에 모델용 폴더를 만들고 다음 파일을 가져온다.

- `exports/POWER_HintPaper.fbx`
- `textures/Paper_Print_BaseColor.png`
- `previews/Paper_UI.png` — 클릭 확대용 투명 PNG

`.blend`, `build_paper.py`, `checks`는 Unity로 가져올 필요가 없다. FBX의 Scale Factor는 1, Generate Colliders는 OFF로 둔다.

## 2. 외부 재질 두 개 만들기

Project 창에서 Create → Material로 재질 두 개를 만든다. FBX 내부의 재질을 다른 재질의 칸에 끌어 넣지 않는다.

| 재질 이름 | Shader | Base Map / Base Color | Metallic | Smoothness |
|---|---|---|---:|---:|
| M_HintPaper | Universal Render Pipeline/Lit | Paper_Print_BaseColor / 흰색 FFFFFF | 0 | 0.05 |
| M_HintTape | Universal Render Pipeline/Lit | 이미지 없음 / B3A37A | 0 | 0.08 |

둘 다 Surface Type Opaque, Alpha Clipping OFF, Emission OFF로 둔다.

Paper_Print_BaseColor 텍스처는 Texture Type Default, sRGB ON, Max Size 2048, Compression None으로 적용한다. 종이가 갈색이나 회색으로 중복 착색되면 M_HintPaper의 Base Color를 흰색으로 확인한다.

FBX를 선택하고 Materials 탭의 Remapped Materials에서 다음과 같이 연결하고 Apply 한다.

- `RLYP_Paper` → `M_HintPaper`
- `RLYP_Tape` → `M_HintTape`

## 3. 기존 벽 종이의 외형 교체

앞서 만든 `Environment/POWER_Hint`가 있다면 그 오브젝트를 유지한다. Box Collider와 PowerHintInspect를 제거하지 않는다.

1. 기존 자식 `WorldPaper`만 비활성화한다. 새 모델과 글자가 겹치지 않게 하기 위한 것이다.
2. `POWER_HintPaper.fbx`를 `POWER_Hint` 아래에 넣는다.
3. 새 모델의 **Local Transform**을 아래 값으로 입력한다.

| 항목 | X | Y | Z |
|---|---:|---:|---:|
| Position | 0 | 0 | 0 |
| Rotation | 0 | 180 | 0 |
| Scale | 1 | 1 | 1 |

```text
Environment
└─ POWER_Hint                 ← 기존 Box Collider / PowerHintInspect 유지
   ├─ WorldPaper              ← 비활성화
   └─ POWER_HintPaper         ← 이번 모델
```

POWER_Hint를 아직 만들지 않았다면 먼저 앞서 제공한 `POWER_HINT_v01/적용안내.md`의 Collider·클릭 확대 연결을 진행한다. 벽의 WorldPaper Canvas 대신 이번 FBX를 넣으면 된다.

앞서 안내한 POWER_Hint 기준값:

- Local Position `(3.2, 1.65, 5.74)`
- Local Rotation `(0, 0, -3)`
- Local Scale `(1, 1, 1)`
- Box Collider Center `(0, 0, 0.004)`, Size `(0.30, 0.42, 0.01)`, Is Trigger OFF
- Environment의 직접 자식으로 배치한다. 크기가 늘어난 벽 Cube의 자식으로 넣지 않는다.

이 위치는 기존에 확인한 뒤쪽 콘크리트 벽 기준이다. 이후 벽을 옮겼다면 현재 벽 표면에 맞춰 위치를 조정한다. Unity에서 뒷면만 보이거나 벽 속에 숨는지는 직접 확인해야 한다.

## 4. 클릭 확대 화면도 같은 종이로 교체

이 단계는 앞서 만든 `Canvas/PowerHintView/PaperPivot/Paper`가 있을 때 적용한다.

1. Project에서 `Paper_UI.png`를 선택한다.
2. Texture Type `Sprite (2D and UI)`, Sprite Mode `Single`, Mesh Type `Full Rect`로 변경한다.
3. Alpha Source `Input Texture Alpha`, Alpha Is Transparency ON, Max Size 2048, Compression None으로 Apply 한다.
4. Hierarchy의 `Canvas/PowerHintView/PaperPivot/Paper`를 선택한다.
5. Image의 Source Image에 `Paper_UI`를 넣고 Color를 흰색, Alpha 255로 둔다.
6. Image Type `Simple`, Preserve Aspect ON, Raycast Target OFF로 둔다.
7. Paper 아래의 기존 `Numbers` 오브젝트만 비활성화한다. PNG에 숫자가 이미 들어 있다.

PaperPivot의 크기 420 × 588, 기존 드래그·확대 코드와 참조는 유지한다. 종이 주위의 어두운 배경은 기존 PowerHintView가 담당한다.

## 5. 간단히 확인

- 벽 종이에 `70`과 `30`만 보이고 숫자가 겹치지 않는지 확인한다.
- 클릭하면 같은 종이 그림이 확대되고, 기존 드래그·휠·닫기가 동작하는지 확인한다.
- 정전 상태에서도 기존 손전등/비상 조명 등으로 발견할 수 있는지 확인한다. 외형은 발광하지 않는 일반 종이 재질이다.

제작 검증: Blender에서 실물 크기, 앞면 방향, UV·재질, FBX 재수입 크기 비교를 확인했다. 미리보기는 실제 Blender 렌더이며 Unity 플레이 검증은 하지 않았다.
