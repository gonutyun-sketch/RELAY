# ELEVATOR v01

기존 회색 상자 엘리베이터의 치수에 맞춘 외형 모델입니다. 작업 범위는 캐빈, 좌우 슬라이딩 도어, 도어 트랙입니다. Unity 프로젝트 밖에 보관하며, 이번 작업에서는 Unity 씬·스크립트·물리 설정을 변경하지 않습니다.

`RELAY_MineElevator.blend`는 부품별 편집 원본이며 닫힌 문 상태입니다. `RELAY_MineElevator_Review.blend`는 문을 열고 카메라·스튜디오 조명을 넣은 감상용 파일입니다. `previews/ELEVATOR_overview.png`는 실제 모델의 Blender 렌더입니다. 이 미리보기의 스튜디오 배경은 모델에 포함되지 않습니다.

모델 전체는 삼각형 32,460개입니다. 본체 실제 외곽 폭은 약 3.09m이고, 지붕 위 인양 고리를 포함한 최고점은 바닥 위 약 3.545m입니다. 문 레일을 포함한 전체 폭은 5.06m입니다. 기존 바닥과 벽의 외곽을 넘지 않게 본체를 만들었고, 인양 고리는 기존 지붕보다 약 0.245m 높으므로 추후 승강로를 만들 때 상부 여유를 확보합니다.

## 텍스처와 재질

`textures` 폴더의 PNG 두 개는 목재·철제 표면의 기본색 텍스처입니다. Blender 원본에는 이미지도 내장했습니다. FBX를 옮길 때는 `textures` 폴더를 함께 보관합니다. Unity에서는 추후 URP/Lit 외부 재질을 만들고 연결할 때 사용하며, 오늘은 연결 작업을 진행하지 않습니다.

| 재질 | Base Map | Metallic | Smoothness |
| --- | --- | ---: | ---: |
| RLYE_Iron | `RLYE_Iron_BaseColor.png`, 색상 White | 0.55 | 0.38 |
| RLYE_Timber | `RLYE_Timber_BaseColor.png`, 색상 White | 0 | 0.12 |
| RLYE_FadedPaint | HEX `666857` | 0.15 | 0.28 |
| RLYE_WornSteel | HEX `858679` | 0.80 | 0.57 |
| RLYE_Oxide | HEX `604638` | 0.12 | 0.08 |
| RLYE_Ochre | HEX `A8904E` | 0.10 | 0.26 |
| RLYE_Dark | HEX `222521` | 0 | 0.08 |

모든 재질은 Opaque이고 Emission은 사용하지 않습니다. 철망은 투명 텍스처가 아닌 실제 막대 메시이므로, 빈 부분을 통해 이후 승강로 환경이 보입니다.

## 파일과 원점

단위는 **미터**입니다. 아래 좌표는 Unity 기준으로 **+Y가 위, +Z가 출입구 앞, −Z가 캐빈 안쪽**입니다.

| FBX | 원점 | 나중에 배치할 기준 |
| --- | --- | --- |
| `ELEVATOR_Cabin.fbx` | 기존 `ELEVATOR_Module` 원점 | 모듈 아래 로컬 위치 0, 회전 0, 크기 1 |
| `ELEVATOR_DoorLeft.fbx` | 왼쪽 문 패널 중심 | 기존 `Door_Left` 아래 로컬 위치 0, 회전 0, 크기 1 |
| `ELEVATOR_DoorRight.fbx` | 오른쪽 문 패널 중심 | 기존 `Door_Right` 아래 로컬 위치 0, 회전 0, 크기 1 |
| `ELEVATOR_DoorTrack.fbx` | 기존 `ELEVATOR_Module` 원점 | 모듈 아래 로컬 위치 0, 회전 0, 크기 1 |

문은 원본 조립 상태에서 닫힌 중심 좌표가 왼쪽 `(-0.6, 1.5, -0.45)`, 오른쪽 `(0.6, 1.5, -0.45)`입니다. 각 문 FBX 자체의 원점은 패널 중심이므로, 기존 문 오브젝트 아래에 넣을 때 이 좌표를 다시 더하지 않습니다.

저장된 Unity 씬의 문은 열린 위치인 왼쪽 `(-1.85, 1.5, -0.45)`, 오른쪽 `(1.85, 1.5, -0.45)`에서 시작합니다. 기존 동작은 각각 X축으로 1.25m 이동하여 닫힙니다. 트랙은 이 이동량을 수용하도록 X축 약 `-2.53~2.53`까지 뻗으며, 캐빈 본체의 약 `-1.7~1.7` 범위보다 넓습니다.

## 맞춤 기준

- 바닥 윗면: Y `0`
- 좌우 벽 안쪽 면: X `±1.2`
- 뒷벽 안쪽 면: Z `-2.75`
- 천장 안쪽 면: Y `3`
- 기존 문 패널: 폭 `1.2`, 높이 `3`, 두께 `0.16`

망 또는 개방부 너머는 비워 둡니다. 이후 흙·암석으로 된 승강로를 추가할 때 바깥 환경이 보이도록 하는 구성입니다. 오늘 범위에는 실제 조명 기구 모델, 조작 버튼 모델, 승강로 흙·암석, 상승 연출/VFX가 포함되지 않습니다. 조명 및 외부 재질 매핑도 사용자 결정에 따라 보류합니다.

## 추후 수동 통합 시

기존 `ELEVATOR_Module`, `Door_Left`, `Door_Right`와 모든 Collider, Rigidbody, 탑승 트리거, 버튼, 스크립트 및 참조를 유지합니다. 좌우 문은 기존처럼 `ELEVATOR_Module`의 직계 자식으로 남겨 둡니다. 새 외형을 위 표의 기준으로 자식 배치한 뒤, 겹치는 회색 상자의 **시각용 Renderer만** 끕니다. 기존 오브젝트 전체를 비활성화하거나 삭제하지 않습니다.

치수와 피벗은 저장된 `Startup_Graybox.unity` 및 엘리베이터 스크립트를 읽어 확인한 기준입니다. Unity 가져오기, 씬 배치, 실행 및 플레이 테스트는 이번 작업에서 수행하지 않았습니다.
